# Publisher verification

This repository serves the AdMob publisher-verification file at:

https://pquilty79.github.io/app-ads.txt

GitHub Pages project sites cannot place a file at the domain root. This small publisher site provides that root file while the Ratastrophe product/support/privacy website remains in its separate repository:

https://pquilty79.github.io/ratastrophe-site/

The entry authorizes the Google AdMob publisher associated with Ratastrophe’s configured ad units. It contains a public publisher identifier, not a secret API key. No app data, analytics, or customer information is stored here.
